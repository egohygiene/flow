## Introduction

This directory contains the foundation-layer architecture document specifications
for Aether.

These specifications define how the core architectural documents describing a
project's foundations, systems, structure, methodology, and roadmap should be
written.

The documents in this directory should be read together, but each owns a
distinct concern.

## Included Specifications

- `foundations.spec.md`
- `system.spec.md`
- `architecture.spec.md`
- `methodology.spec.md`
- `roadmap.spec.md`

## Recommended Reading Order

1. `foundations.spec.md`
2. `system.spec.md`
3. `architecture.spec.md`
4. `methodology.spec.md`
5. `roadmap.spec.md`

## Ownership Model

- `FOUNDATIONS.md` defines enduring assumptions, invariants, and architectural
  truths.
- `SYSTEM.md` defines the major systems, their responsibilities, and their
  conceptual boundaries.
- `ARCHITECTURE.md` defines the structural organization of those systems.
- `METHODOLOGY.md` defines how the organization or product intentionally builds,
  evolves, and validates work.
- `ROADMAP.md` defines long-term strategic direction and capability evolution.

## Notes

These specifications extend the architecture document standard defined by
`document.spec.md` and are intended to be paired with reusable skill folders in
Aether.
