# Phase Design Checklist

Use this checklist while reviewing an implementation plan.

- [ ] Each phase delivers an independently reviewable outcome.
- [ ] Prerequisites and dependencies are explicit.
- [ ] Requirements and acceptance criteria map to concrete steps.
- [ ] Validation commands or checks exist for each meaningful phase.
- [ ] Migration, rollback, or recovery concerns are called out when relevant.
- [ ] Architecture decisions are treated as constraints, not suggestions.
- [ ] Open questions are separated from approved work.
