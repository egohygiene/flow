# Cleanup Classification Checklist

Classify each cleanup candidate before changing it.

- safe mechanical cleanup
- safe documentation or configuration correction
- behavior-affecting change requiring separate authorization
- uncertain ownership or usage
- generated or externally managed artifact
- unrelated change outside scope

Before finalizing, confirm:

- [ ] only safe categories were edited
- [ ] deletions have clear ownership and recovery understanding
- [ ] validation covers any behavior-sensitive configuration change
- [ ] unrelated churn is absent from the diff
