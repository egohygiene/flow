# Architecture Document Sequencing

Use dependency order rather than alphabetical or directory order.

A common sequence is:

    PURPOSE
        ↓
    VISION
        ↓
    PRINCIPLES
        ↓
    PILLARS
        ↓
    FOUNDATIONS
        ↓
    ONTOLOGY
        ↓
    SYSTEM
        ↓
    ARCHITECTURE
        ↓
    METHODOLOGY
        ↓
    ROADMAP

Use specification metadata as the source of truth. Do not create every possible
document automatically.
