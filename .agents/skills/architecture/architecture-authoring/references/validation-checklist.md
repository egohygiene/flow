# Architecture Validation Checklist

## Structural

- [ ] Frontmatter parses.
- [ ] Required metadata exists.
- [ ] Artifact ID is stable.
- [ ] Exactly one H1 exists.
- [ ] Heading levels are valid.
- [ ] Markdown passes tooling.

## Relationships

- [ ] Dependencies resolve.
- [ ] No dependency cycle exists.
- [ ] Supersession is valid.
- [ ] Ownership does not conflict.

## Semantic

- [ ] The document addresses its declared concern.
- [ ] Responsibilities are explicit.
- [ ] Non-responsibilities are explicit.
- [ ] Canonical terminology is preserved.
- [ ] Unresolved questions remain visible.

## Evidence

- [ ] Observations differ from inference.
- [ ] Decisions differ from proposals.
- [ ] Assumptions are labeled.
- [ ] Missing evidence is acknowledged.
- [ ] Contradictions remain visible.
