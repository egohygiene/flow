# Create Purpose Document — Examples and Anti-Patterns

## Primary Question

    Why does this exist, for whom, and what enduring value should it create?

## Strong Output Characteristics

- specific enough to guide decisions
- durable across implementation changes
- aligned with upstream identity
- honest about uncertainty
- bounded against adjacent documents
- understandable without source-code knowledge

## Strong Example

    Help people cultivate healthier relationships with themselves, others, and technology through intentional, human-centered tools and practices.

## Anti-Pattern

    Build a React application with AI journaling and dashboards.

## Review Questions

- Does the text answer the primary question directly?
- Is any content owned by another identity document?
- Would this still make sense after a major implementation change?
- Are claims supported or labeled as assumptions?
- Could a contributor use this document to evaluate a real decision?
