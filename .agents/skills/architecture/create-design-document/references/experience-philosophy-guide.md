# Experience Philosophy Guide

## Design Intent Versus Implementation

    intent:
    The experience should feel calm, legible, and respectful of agency.

    implementation:
    Use a specific animation library and a twelve-column grid.

`DESIGN.md` owns the first statement. Implementation artifacts own the
second.

## Experience-Quality Test

A useful experience quality should:

- describe a perceivable characteristic
- influence real design decisions
- remain meaningful across technologies
- trace to human needs or project principles
- avoid claiming one universal emotional response

## Required Review Lenses

- accessibility
- agency and control
- cognitive load
- error prevention and recovery
- trust and transparency
- cultural and contextual interpretation
- sensory intensity and reduced motion
- product identity versus shared commitments

## Common Failure Modes

- aesthetic moodboard presented as philosophy
- implementation rules presented as values
- delight prioritized over completion
- engagement treated as benefit
- accessibility deferred to the component layer
- every product forced into one identical visual identity
