# ONTOLOGY.md Validation Checklist

## Specification

- [ ] `architecture-ontology` is identified.
- [ ] The governing version is known.
- [ ] Required upstream artifacts have been read.

## Primary Question

- [ ] The document answers:
      What exists in this domain, what does each concept mean, and how do the concepts relate?

## Boundaries

- [ ] Responsibilities are explicit.
- [ ] Non-responsibilities are respected.
- [ ] Implementation details are excluded.
- [ ] Adjacent concerns are not duplicated.

## Evidence

- [ ] Observation, inference, and assumption are distinguishable.
- [ ] Provenance is preserved where required.
- [ ] Missing evidence is acknowledged.
- [ ] Contradictions remain visible.

## Completion

- [ ] Acceptance criteria from `architecture-ontology` pass.
- [ ] Downstream impacts are recorded.
- [ ] Metadata and Markdown pass repository checks.
