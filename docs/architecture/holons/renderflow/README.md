# Renderflow Holon Contract

Renderflow owns spec-driven transform graphs and reproducible derivative builds,
currently centered on publication-ready documents plus image and audio format
conversion. It plans supported paths, shares intermediates, executes independent
work, and collects outputs.

This contract is grounded in `egohygiene/renderflow` revision
`103a01e20f3dd486856c7583cbaceef4922eb473` (workspace v0.2.1), inspected on
2026-08-13. The current repository already separates core, CLI, and plugin SDK.
General video-derivative packaging is not treated as an existing capability.
