# Aniflow Holon Contract

Aniflow owns temporal video processing: inspect a video, decompose it into
ordered media components, apply ordered domain processors, validate continuity,
and reconstruct a release-ready master.

This contract is grounded in `egohygiene/aniflow` revision
`20783d7374298e5fd44c782348a3c944c9318656` (package v0.2.0), inspected on
2026-08-13. It defines intended integration boundaries; it does not claim
that the current single-crate code already exposes the final library contract.
