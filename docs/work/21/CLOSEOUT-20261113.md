## Concrete scope

- Preview reports categories, exclusions, redaction policy, privacy warnings,
  exact member count and encoded-size estimate without writing or discovering.
- Explicit creation writes one fresh bounded 0600 Unix JSON support artifact;
  existing files/aliases are refused, identity/content is reobserved, and partial
  output is preserved on failure. Inspection verifies typed structure and an
  explicitly named supported digest without extraction or embedded execution.
- Only generated build/platform/support-contract/compiled-health facts enter
  members. No attachment or raw-log category exists. Unobserved runtime health
  remains unknown/null; no subscriber, exporter, provider or collector starts.
- Product-owned command names/envelopes/exit policies remain intact. Support
  success never creates domain acceptance, approval, resumability or a release.
- Schemas, native Task aliases, a local collector *candidate*, operator runbooks,
  source-local refusal cases and a shared explicit-built-CLI driver are authored.
  The driver reads its shared case inventory and records actual binary/case
  observations only if it is executed.

The Unix file adapter uses nonfollowing/nonblocking reads and observed identity
checks. It is not a filesystem snapshot, hard kernel deadline or OS memory
sandbox. File I/O is explicitly unsupported on hosts without that identity
adapter; Windows qualification stays with the platform owners (#71/#72).
Output/input lengths are bounded (64 KiB archive, 4 KiB request/member, four
members), with serde's bounded recursive parser; actual peak RSS has not been
measured or given an OS-enforced budget.
